===================
RTL-SDR Blog V4
===================

V4L（V4 Lite）精简版
=======================

R828D 芯片全球大面积停产，官方为了保证产品线不中断，改用了 R828S 芯片并进行了重新设计，推出了V4L（V4 Lite）精简版:

- 射频芯片更换（R828D => R828S），由于 R828S 的内部电路架构有所不同，官方重新设计了 PCB 布局
- 频率范围基本一致: V4L 依然保留了从 **500 kHz 到 1.76 GHz** 的连续接收能力，并且同样内置了 HF（短波）频段的上变频（Upconverter）电路

V4L 和 V4 的优化和区别:

- 体积与功耗更小（Lite 化）

  - 电路精简： 删减了部分冗余的供电和滤波元件，整体 PCB 更加紧凑
  - 功耗与发热降低： 运行时的发热量比原版 V4 有所改善

- 滤波与抗干扰调整

  - 原版 V4 拥有非常复杂的内置三段式切片滤波器（高通/低通/带通组合）, V4L 对内部的射频前端滤波电路进行了重新微调，以匹配 R828S 的输入阻抗
  - 在大部分日常频段（如 V/U 频段、FM 广播、ADS-B）的灵敏度与 V4 几乎没有差别，但在极个别强信号干扰严重的频段，抗过载能力与原版 V4 略有微调

实际上现售的V4 (R828D) 性能极其出色，原版 V4 采用的 R828D 芯片配上完整的三段式硬件滤波电路，在短波（HF）和抗强干扰能力上是历代最强的。V4L 只是“供应链替代版”： 官方推出 V4L（Lite）的核心原因是 R828D 停产买不到货，才逼迫官方换成 R828S。在实际接收效果上，V4L 相较于原版 V4 并没有带来“性能飞跃”，甚至原版 V4 在部分频段的滤波用料更足。

驱动安装
===========

**在 Linux (如 Ubuntu/Debian) 下配置驱动时，千万不要直接用系统自带的旧版本**

老版驱动不认识 R828D / R828S 的上变频架构，会导致低频段收不到信号。必须按照官方 GitHub 的说明，编译安装 RTL-SDR Blog 专门分支的驱动（rtlsdr-blog）:
