================
玩无线电
================

无线电（Radio Frequency, RF）是一个将物理学、数字信号处理、微波工程与动手实践完美结合的硬核领域。

4个极客无线电玩乐方向
=======================

软件定义无线电（SDR, Software Defined Radio）
----------------------------------------------

传统无线电靠复杂的电容、电感硬件电路解调信号；SDR 则是将原始射频信号直接采样，交由 Linux 系统中的软件（如 GNU Radio、SDR++）进行数字信号处理。

只需要插入一块几百元的 RTL-SDR 或 HackRF 开发板，连接电脑或 3D 打印的专用接收天线:

- **接收 NOAA 气象卫星云图** : 在气象卫星过境时，抓取其 **137 MHz** 的 FM 信号，在 Linux 下用软件实时解码出高清地球云图
- **监听 ADS-B 飞机信号** : 接收 **1090 MHz** 的民航广播信号，搭建属于你自己的个人雷达站，在 Web 界面上实时追踪方圆数百公里内所有飞机的航速和高度
- **捕获 FM / 短波广播与无线调频** : 实时解调和分析周围所有的无线通信频谱

业余无线电（Amateur Radio / :ref:`ham` ）与无线电台
------------------------------------------------------

通过合法考取业余无线电操作证书，获得特定频段（如 **144 MHz/430 MHz 或HF端波段** ）的发射许可:

- **通联全球（DX）** : 利用短波电台（HF）和电离层折射，在夜间与几千公里外的全球无线电爱好者进行语音或摩尔斯电码（CW）通联。
- **SSTV（慢扫描电视）** : 接收国际空间站（ISS）通过无线电波发回的图片，或用自己的电台将图片调制成声波发射出去
- **业余卫星通联** : 制作定向天线，在业余通信卫星划过天际的几分钟窗口期内，利用微弱信号完成跨国通联

开源图传与数字通信协议（与无人机/机器人联动）
-----------------------------------------------

深入通信协议底层，研究无线数据是如何打包、调制和抗干扰:

- **ExpressLRS (ELRS) 源码与硬件** : 深入学习 **2.4 GHz / 915 MHz** 的长距离高刷新率控制链路（LoRa 调制），甚至尝试自制小功率发射/接收模块
- **penIPC / OpenHD** : 探索如何利用普通 Wi-Fi 网卡的“包注入（Packet Injection）”模式，绕过传统 TCP/IP 握手协议，实现极低延迟的高清数字视频传输

硬件 DIY：自制收音机、天线与超外差电路
------------------------------------------

- 从最原始的矿石收音机（无源无电源，纯靠电磁波能量驱动耳机发声）开始，理解 LC 谐振电路
- 组装或焊接经典的超外差式调频/调幅收音机套件（如六管/七管收音机），用示波器和信号源调试中频放大电路
- 利用 3D 打印件、铜管和同轴电缆，自己设计并打印出各种增益天线（如八木天线 Yagi、双黑黑天线、莫克森天线 Moxon）

系统化的入门学习路线
=====================

无线电的知识体系非常庞大，所以学习线路可以从 ``从软件/感知入手 -> 考证合法发射 -> 深入物理天线与硬件``

- 第一阶段：软无入门（SDR 视界，零发射风险）:

  - 硬件准备: 购买 :ref:`rtl-sdr_v4` (我花了419元购买了V4主机和天线套装)
  - 软件环境: 在 Linux / Mac 下安装 SDR++、Glogg 或 GNU Radio
  - 理论学习: 理解频率（Frequency）、带宽（Bandwidth）、调制方式（AM 调幅、FM 调频、SSB 单边带）以及采样率的概念
  - 实践目标: 成功接收当地 FM 广播，随后尝试用天线抓取并解码 NOAA 18/19 号气象卫星图

- 第二阶段：考取 HAM 执照（合法合规玩电台）:

  - 考取 A 类 :ref:`crac_amateur_radio_operator_certificate`
  - 设备选用: 购买一台入门手台（如泉盛 UV-K5，这台机器非常受极客欢迎，因为它的固件完全开源，可以通过刷入开源固件解锁频谱仪、接收航空频段等各种神仙功能）

- 第三阶段：深入天线与电磁场原理:

  - 核心概念： 阻抗匹配（50欧姆）、驻波比（SWR）、驻波表的使用、半波长偶极天线（Dipole）、天线增益（dBi）
  - 实践项目： 3D 打印一个八木天线的固定支架，用卷尺或铜棒按计算好的尺寸切割天线振子，做一把手持定向天线去野外对准业余卫星或 ISS 进行信号对焦

- 第四阶段：进阶 DSP 与硬件电路设计:

  - 理论教程:

    - 《大话无线通信》：非常适合软件工程师的通俗入门读物
    - 《ARRL Handbook》（美国业余无线电协会手册）：无线电领域的“圣经”，涵盖从基础电路到天线、高频功放的所有内容
    - Great Scott Gadgets 的《Software Defined Radio with HackRF》：免费的视频教程，从信号处理基础手把手教你理解无线电

  - 高级实践： 使用 GNU Radio Companion (GRC)，用拖拽模块的方式搭建自己的数字调制/解调器（如 BPSK、QPSK），将文本直接调制成无线信号
