===========================
AMD Instinct MI50 shroud
===========================

MI50散热方案
===============

**我选这款** => `AMD Instinct MI50 shroud <https://www.printables.com/model/1421067-amd-instinct-mi50-shroud/>`_ 组合公版风扇:

- ``BASA0725R2U`` 公版涡轮显卡风扇，淘宝上购买大约10-12元
- 3颗M2x4沉头螺钉，用于安装风扇
- 5颗M2x6螺钉（粗牙），用于将风扇罩固定到显卡罩上
- 这种内置涡轮风扇实际上是AMD官方Pro VII的改版，气流从散热片中间通过，所以散热效果较好

`AMD Radeon Mi50 shroud for BFB0712HF blower fan <https://www.printables.com/model/1475886-amd-radeon-mi50-shroud-for-bfb0712hf-blower-fan>`_  方案类似:

- ``BFB0712HF`` 65 毫米显卡散热风扇(原先用于NVIDIA GTX 970 980 980Ti 1060 1070 1070Ti 1080 1080Ti 静音冷却风扇)
- 打印时，将顶部（带风扇孔的部分）放置在打印平台上，并将支撑结构设置为仅与打印平台接触
- **在 Superposition 1080p 高画质测试中，这种设计使显卡温度比三风扇型号低约 10 摄氏度，得分高出约 1500 分**

`AMD Radeon Instinct MI50 Triple Slim 80mm Fan Shroud <https://www.printables.com/model/1413245-amd-radeon-instinct-mi50-triple-slim-80mm-fan-shro>`_ 和下文 **mi50改装联想4090散热器** 实际相同，缺点是双槽显卡会增厚为3槽

其他散热参考
---------------

B站有很多UP主介绍MI50的使用(毕竟这块32G卡曾经非常价格低廉)，也包括各种散热改装视频:

- `噪音消失术！看MI50独立温控散热器如何实现极致静音与低温 <https://www.bilibili.com/video/BV1vJxbzpELS/?spm_id_from=333.337.search-card.all.click&vd_source=9e81a12fc8eb4223ba7650a40a5ce9a7>`_ 比较复杂的结构，需要电焊，并且外壳较突起，可能无法实现双卡紧贴安装；好处是焊接了温控可以不用再通外部程序调速
- `mi50改装联想4090散热器，风扇完美温控 <https://www.bilibili.com/video/BV16mN9zmEed/?spm_id_from=333.337.search-card.all.click&vd_source=9e81a12fc8eb4223ba7650a40a5ce9a7>`_ 店家改装280元，外加了拆机的4090风扇，压制温度效果可能较好，但是显卡会增厚为3槽厚度
