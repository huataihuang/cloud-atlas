=================
Python列表
=================

列表(list)由一系列按特定顺序排列的元素组成。列表中通常包含多个元素(任何都可以加入列表，列表的元素可以没有任何关系)，因此给列表指定一个表示复数的名称(如letters, digits 或 names)是好方法。

在Python中，用方括号 ``[]`` 表示列表，用逗号分隔其中的元素。

访问列表元素
=============

Python中，第一个列表元素的索引是 ``0`` ，最后一个列表元素的索引是 ``-1``
