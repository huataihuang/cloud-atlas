=====================
VS Code扩展
=====================

.. note::

   参考gemini建议结合实际实践整理

通用插件(跨语言卡肺癌)
========================

- ``GitLens`` : 深度集成 Git 历史、Blame 追溯和代码修改行上下文。软件核型功能免费使用，应该已经足够，Pro版本需要收费。另外虽然首次使用会引导登录，但实际使用不需要登录。

- ``Continue`` : 本地 AI 辅助插件

- ``vim`` : :ref:`vscode_vim` 类模拟插件可以保持和Linux服务器开发的一致性体验，持续训练保持肌肉记忆。
