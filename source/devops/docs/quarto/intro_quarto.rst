=====================
Quarto简介
=====================

我是在学习 :ref:`practical_deep_learning_for_coders` 发现 `fast.ai <https://www.fast.ai/>`_ 开发的 :ref:`nbdev`  采用了 ``Quarto`` 来发布文档(网站)，能够更好的使用机器学习发布模型算子以及配套的文档。这引起我对该文档系统的兴趣，期望在 :ref:`machine_learning_learning_roadmap` 实践中能够用上这项技术。

`Quarto官网 <https://quarto.org/>`_ 说明了Quarto是一个开源的可续和技术发布系统:

- 作者使用 :ref:`jupyter` notebooks或文本编辑markdown
- 使用 :ref:`python` , R, Julia 和 Observable创建动态内容
- 使用HTML, PDF, MS Word, ePub 以及更多格式发布可重用，产品质量的文档那个，出版物，控制面板，网站，博客以及书籍
- 可以将知识和良好组织的内容到Posit Connect, Conflunce 以及其他发布系统
- 使用Pandoc ``markdown`` 撰写文档, 包括公式、引用、交叉引用、图表面板、提示框(callouts)、高级分布等丰富功能
