=========================
Astro简介
=========================

**Astro** 适应构建 ``内容驱动网站`` (博客、市场营销、电子商务)的web框架。Astro采用了名为 ``Islands architecture`` (群岛架构)的新型前端模式，将大部分页面渲染为快速且静态的HTML，并在页面上需要交互或者个性化的区域(如 ``轮播图`` )添加上小型的JavaScript"群岛"。这种方式避免了单体JavaScript负载对于许多其他现代JavaScript Web框架响应速度的影响。

群岛架构
==========

.. note::

   “群岛” 架构的总体思想: 在服务器上渲染 HTML 页面，并在高度动态的区域周围注入占位符或插槽 […] 这些区域随后可以在客户端 “激活” 成为小型独立的小部件，重用它们服务器渲染的初始 HTML。 — Jason Miller, Preact 的创造者

在 Astro 中，Island 是 HTML 静态页面上的增强的动态 UI 组件。

客户端群岛是一个交互式的 JavaScript UI 组件，它在页面的其余部分中单独进行 ``hydrated`` (水合)，而服务器群岛作为一个 UI 组件则是在页面的其余内容中，通过服务器端单独渲染其动态内容。

群岛组件
-------------

Astro 组件是页面模板构建的基础。它们被渲染成静态的 HTML 而无需客户端运行时。

你可以将客户端群岛想象成一个个交互式小组件，漂浮在静态、轻量级、服务器渲染的 HTML 海洋中。

单个岛屿始终独立于页面上的其他岛屿运行，且一个页面上可以存在多个岛屿。尽管客户端岛屿在不同的组件上下文中运行，但它们仍然可以共享状态并相互通信。

这种灵活性使得 Astro 能够支持多个 UI 框架，如 React、Preact、Svelte、Vue 和 SolidJS。由于它们是独立的，你甚至可以在每个页面上混合使用多种框架。
